# 작업 패키지 — 긴급과학 (영어권 미국 채널, 긴 판 3편을 통과 수준까지)

## 0. 먼저 읽을 것 (너는 이 작업의 앞선 대화를 모른다)

- 너는 Claude Code 클라우드 세션이다. 이 작업은 다른 대화(로컬 PC)에서 시작됐고, 너는 그 대화를 전혀 모른다. **이 파일과 아래 부록이 전부다.** 파일 밖에 있는 것은 존재하지 않는다고 생각하고 일한다.
- 너에게 없는 것: 로컬 PC의 폴더, 로그인된 브라우저, GPU, 로컬 실행 도구(agy, gcloud 등), Codex, 아르곤(Gemini 4 Argon) 호출 수단, Vertex AI 호출 수단, 이미지·영상·음성 생성 도구. 이 작업에는 API 키가 필요 없다(4번 참조).
- 너에게 있을 수 있는 것: 이 저장소의 파일, 웹 검색과 웹 페이지 열기(막히면 "미확인"), Claude 서브에이전트(동시에 최대 10개).
- 사용자에게 아무것도 묻지 않는다. 판단이 필요하면 추천안을 정하고 "이렇게 정했고, 이유는 ~"이라고 적는다. 2번의 확정사항은 그대로 따른다.

### 이 작업이 하는 일 (한 문장)
긴급과학 채널(영어권 미국 시청자용 과학 개그 롱폼, 9분대 긴 판)의 편 3개를 **그림·영상·음성을 만들기 직전 단계까지 "통과" 수준으로** 끝낸다. 편 1(테슬라 로드스터)은 확정된 대본 v5를 검토·보강하고, 편 2(AI 생물학)와 편 3(상온 초전도체)은 소재풀에서 새로 만든다. 통과란 10번의 13개 체크를 모두 "맞음"으로 넘긴 상태다. 점수로 정하지 않는다. 완료 한 줄 기준: 10번 13개가 전부 맞음이고 결과 맨 아래에 '로컬 판정 대기'가 적혀 있다. 어김이 남으면 한 번 고쳐 다시 판정하고, 그래도 어김이면 미완료로 보고하며 이유를 적는다.

### 시작 순서
1. 이 파일 끝까지 읽는다(특히 1·2·3·10번).
2. 부록 A·B·C·E·F를 모두 읽는다(D는 이 패키지에 없다). 부록 E는 스킬 원문이다. 이 작업에 쓰는 스킬은 부록 E의 원문만 따른다.
3. `00_점검_000_읽은것표.md`를 쓴다(9-6 형식). 편 1·2·3 각각 "이미 된 것 / 빠진 것 / 충돌" 표.
4. 편 1·2·3을 5번 단계대로 진행한다. 편마다 서브 5개(작성 3, 검토 2)를 쓴다. 동시에는 두 편까지만 돌린다. 세 번째 편은 앞 두 편이 끝난 뒤 시작한다(동시 서브 최대 10개).
5. 끝에 `99_요약_000_긴급과학3편.md`를 쓴다(10번 체크 표와, 로컬 판정에 넘길 질문 3개. '바로 쓸 것 3개'와는 다른 것이다).

## 2. 확정사항 요약 (사용자가 정한 것, 충돌하면 이긴다)

- 영어, 미국 시청자. 긴급과학식: 속보 하이텐션, 쉬운 비유, 게임·테크 밈.
- 긴 판(9분대)만 만든다. 낭독 1,400~1,600단어. 압축판은 없다.
- 목소리는 Will로 확정. 이번 작업은 음성을 만들지 않는다.

## 7. 결과 파일 형식과 이름

- 파일 이름: `종류번호_종류_편번호_짧은제목.md`. 5단계 파일 이름의 00N은 편 1=001, 편 2=002, 편 3=003으로 바꿔 쓴다.
  - 종류번호는 고정이다: 00 점검 / 01 사실표 / 02 대본 / 03 현지화 / 04 장면 / 05 그림목록 / 06 모션계획 / 07 자기검토 / 99 요약.
  - 편번호: 편 1=001, 편 2=002, 편 3=003. 세 편을 함께 다루는 00 점검과 99 요약은 편번호 000을 쓴다.
  - 짧은제목: 편 이름 한 단어(편 1 `로드스터`, 편 2 `AI생물학`, 편 3 `초전도체`). 00 점검과 99 요약은 `읽은것표`, `긴급과학3편`을 쓴다. 대본 파일만 `_vN`을 붙인다.
- 예: `00_점검_000_읽은것표.md`, `02_대본_001_로드스터_v5.1.md`, `02_대본_002_AI생물학_v1.md`, `99_요약_000_긴급과학3편.md`.
- 산출물 개수: 편 3개 × 7개(01~07) = 21개, 합본 2개(00, 99). 총 23개.
- 파일 맨 위에 한 줄 결론과 "바로 쓸 것 3개"(이 파일을 받은 다음 사람이 바로 실행할 수 있는 항목 3개)를 둔다.
- 결과는 `results/` 바로 아래에 둔다. 커밋은 메인만 한다. 현재 체크아웃된 브랜치에 커밋하고 push한다. 새 브랜치를 만들지 않는다. 서브는 파일만 쓴다.

## 10. 통과 기준 (이 13개를 모두 "맞음"으로 넘어야 통과)

편마다 아래 13개를 맞음 / 어김 / 미확인으로 판정한다. 판정마다 근거를 한 줄 붙인다.

1. **첫 15초**: 속보 같은 오프닝 질문이 있고, 시청자가 멈출 이유가 한 문장으로 드러난다.
2. **텐션**: 중간마다 "그래서 어떻게 됐는데?"가 최소 3번 생긴다. 장면표에 표시돼 있다.
3. **비유와 설명**: 어려운 개념 하나마다 쉬운 비유가 하나 있다(편당 최소 3개). 비유가 과학적으로 틀리지 않다.
4. **웃음**: 설명 덩어리마다 농담이 한 줄 있고, 두 번 연달아 치지 않으며 재탕하지 않는다.
5. **사실**: 모든 주장에 사실표 출처와 확인 날짜가 있다. 대본에 쓴 주장은 모두 확정이다. 미확인 주장은 대본에서 빼고 사실표에 '미확인·대본 제외'로 남겼다.
6. **낭독 분량**: 긴 판 기준 1,400~1,600단어(로드스터 v5는 1,534단어).
7. **컷과 장면**: 9분대 기준 컷 150~200개, 30초당 8~12번 교체, 같은 화면 재료가 세 번 연속으로 이어지지 않는다.
8. **실사 비율**: 출발 배합(2번)에 맞는지 장면표 아래에 화면 재료 6종별 컷 수 합계를 적어 집계했다. 어긋나면 이유를 적는다.
9. **그림 필요 목록**: 장면 id별 화면 재료, 장수, 참조 그림 여부, 금지 요소가 적혀 있다.
10. **움직임 계획**: 움직이는 장면(3번 I 정의)이 30% 이상(필수)이고, 장면마다 움직임을 한 줄로 썼다.
11. **끝인사와 자막 명세**: 끝인사가 고정 문구로 있고, 자막 층이 화면에 굽히지 않는다고 명시했다. 두 판 납품과 .srt 동봉이 적혀 있다.
12. **썸네일 문구와 구도**: 글씨가 크고 한 문장이다. 작은 글씨가 없다.
13. **자기 검토**: 검토 서브 ④·⑤가 따로 보고, 메인이 통합했다.

판정 방법: 항목마다 근거를 한 줄 붙인다. 근거 없이 "맞음"이라고 쓰지 않는다. 판단이 애매하면 "미확인"으로 쓰고 이유를 적는다.

클라우드 단계의 통과는 "자체 통과 체크"다. 최종 판정(아르곤 채점)은 결과를 로컬로 가져간 뒤에 한다. 결과 맨 아래에 "로컬 판정 대기"를 적는다.

## 11. 로컬 단계 (클라우드 밖, 참고용)

- 클라우드 결과를 로컬로 가져와 아르곤(agy, 무료 경로)으로 최종 통과 판정을 한다.
- 통과한 편만 그림 생성 경로(로컬 전용)로 넘긴다. 그림 생성은 로컬이 한다.
- 음성은 로컬 유료 계정에서 만든다. 시험은 무료 계정으로 한다. 최종 음성만 유료 계정 것을 쓴다.
- 모션 계획의 실행 도구는 로컬에서 고른다.
