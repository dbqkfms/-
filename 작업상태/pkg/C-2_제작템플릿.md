## 2. 단계별 요령

**사실표.** 항목마다 확인됨 / 추정 / 미확인 / 쓰지 말 것 + 출처 키(S#). 공식 주장(제조사·발표)과 독립 검증을 구분하고, 2차 계산(블로그 추정 등)은 "추정"으로만. 대본 작가는 사실표를 유일한 사실 기준으로 받는다.

**SNS 밈·반응 조사(회의 전, 10-21).** 사실표와 나란히, 이 소재로 사람들이 이미 만든 밈·짤·패러디·리액션 영상·베스트 댓글을 모은다. Haiku 4~6개 병렬, 조각마다 플랫폼·질문 하나(X / Reddit / TikTok·Shorts / YouTube 댓글 / Instagram / 한·일 커뮤니티), 결과는 링크·확인 시각·반응 크기·원본/재게시·AI 생성 여부·권리 상태를 붙인 한 묶음(`SNS반응_v1.md`). 외부 초안에 있던 반응 후보도 버리지 말고 이 묶음에 넣는다(수치가 틀린 초안이어도 반응 후보는 따로 확인한다). 막힌 출처는 막혔다고 적는다. 요청 헤더에 개인 정보 금지.

**회의 재료.** 요청서는 리만 `회의_재료제안_요청.md` 형식 그대로: 훅 후보 3, 꼭 넣을 사실 6~10, 뒷이야기 3~6, 비유 5~8, 농담·밈 5~8, 장면 아이디어 5~8, 친구에게 보내고 싶은 한 순간, 넣지 말 것 3~5. 다른 제안·대본은 보지 말 것을 명시. 모든 참가자에게 SNS 반응 묶음을 주고, 농담·밈은 **이 소재에서 실제로 퍼진 반응**을 먼저 고른 뒤 범용 밈 형식을 보탠다. 장면 아이디어마다 "그림·실사·실제 영상·실사풍 생성·자료 중 무엇일 때 가장 센가"를 한 단어로 적게 한다. 요청서에 "권리 불확실 = 그림 재현이 기본" 같은 문장을 넣지 않는다(발상 단계에서 실사 후보를 미리 지운다). Codex는 `py -3 "...\scripts\codex_sub.py" "작업설명" --workdir <폴더> --write`(Bash 백그라운드).

**한 작가 대본.** 발주서는 리만 `대본작가_발주서.md` 형식: 먼저 읽을 것(확정사항→사실표→원 지시서→지난 편 script_B.md→스킬 content-fun-lens·purpose-first-quality·commercial-grade-content) / 시청자 경험 성공 기준 한 문단 / 이야기 뼈대(메인 판단) / 밈은 `[MEME: 형식 — 우리 그림으로 무엇을]` 막당 1~2개 / 장면마다 `ID | 막 | TTS 스타일 | 화면 의도([CAP][EXT][GEN][MEME][HF]) | 대사` / 끝에 글자 수와 사실표 대응표. 글자 수는 목표 길이 × 약 1,000자/분(Will 1.2배 기준, 나비 실측으로 재조정)으로 잡는다.

**장면 설계·재료 고르기.** 장면 설계표에 처음부터 '재료 종류' 열(a 실영상 / b 생성 그림 / g 실사풍 생성(사진·클립, Omni·Veo·Wan 등) / c 사진 / d 문서 / e 도해·그래프 / f 밈)을 둔다. 종류는 비율을 맞추려고 고르지 않는다. 박자마다 `content-fun-lens` 1절 "재료의 결" 네 질문(실사일 때 더 센가 / 이 소재의 실제 밈은 / 실제라서 신기한가 / 무엇이 이 박자에 가장 센가)으로 먼저 고르고, 배합 비율은 다 고른 뒤 한쪽으로 쏠렸는지 보는 진단으로만 쓴다. 실영상·사진이 막혔을 때 '그림으로 대체'를 기본값으로 두지 않는다: 사용자가 허용한 범위의 짧은 인용(출처 칩) → 같은 사건의 다른 공개 실사·실제 자료 → g 실사풍 생성(가상임을 화면에 밝히고, 업로드 때 YouTube의 합성·변형 콘텐츠 공개 항목 확인. 실존 제품이 실제로 그렇게 했다고 보이게 만들지 않음) → 그래도 안 되면 그림, 순서로 그 박자의 놀람·웃음을 살릴 길을 찾는다. 대체했으면 "원래의 어이없음이 남았나"를 한 줄 적는다. 출발 배합 실영상 15 / 생성 그림 ≤20 / 사진 25~30 / 문서 5~10 / 도해·그래프 25 / 밈 15%. 30초당 8~12회 전환, 연속 두 구간이 같은 종류 금지, 같은 화면 3초 넘게 정지 금지(정지 그림은 느린 줌·이동), 개념 하나에 비유 하나, 핵심 개념 3~4개는 요소가 쌓이는 도해로 10~15초. 글자 카드는 3~4단어 띠, 배경은 흐린 실사(덮개 0.2~0.3). 3D·우주·과학 박자는 `D:\작업_대용량\과학영상_라이브러리`의 실제 움직이는 영상 먼저. 근거 `D:\작업_대용량\긴급과학_원본비교_20261018\느낌비교.md`.
