# 메인 판단 (00 점검 결과 반영, 모든 후속 서브 공통)
- H3 제외(본문 2번 우선, A-1 44줄 무시). Higgsfield 크레딧 경로 안 씀.
- 실사풍 생성 그림 안 씀. 화면 재료는 본문 1번 6종으로만 집계(C-2의 7종 분류는 쓰지 않음).
- 편 1 T63 트럼프 클립 삭제(본문 8번). 실존 인물 놀림은 B-1 기준 4–6곳 이내.
- 편 1 테슬라 공식 영상: 그대로 쓰지 않음, 짧은 인용 최대 9곳, 권리 판단은 로컬 확인 필요(미확인).
- 편 1 은빛 디자인 C. 컷은 150–200(A-6의 242 아님).
- 길이 기준은 1,400–1,600단어(C-2의 1,000자/분 기준 쓰지 않음). 사실 상태는 3단계(확정/추정/미확인).
- 편 3: C-1의 '공중부양 밈 총집합'은 본문 3-C(저작권 클립·밈 직접 사용 금지)와 충돌 → 밈 원본 영상은 쓰지 않고 도해·움직이는 클립으로 재현. 이미 만든 편(원조 2023 벤치마크)과 소재가 겹치지 않게 각도를 '그 이후'(검증·AI 탐색)에 둔다.
