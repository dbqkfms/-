2. 고친다: 대본(02)을 고치면 같은 파일 안에서 고친다(편 2·3은 `_v1` 그대로 두고 파일 안 맨 끝에 `**[검토 반영 변경표]**`를 추가, 편 1은 `_v5.1` 파일의 변경표에 행 추가). 대본이 바뀌면 **03 현지화의 해당 행, 04 장면표의 해당 행(내레이션 구절·시간)과 JSON 블록, 05·06의 관련 행을 같이 고친다.** 편 1은 v5.1에서 바뀐 모든 줄(T02a 포함)을 04의 JSON 블록과 내레이션 칸에 반영하고 `(v5.1 동기화 대기)` 표시를 없앤다. 사실 상태가 바뀌면 01도 고친다. 결과 파일은 덮어쓰되 형식은 유지한다.

4. `/home/user/-/results/07_자기검토_NNN_짧은제목.md`를 쓴다(9-11): 맨 위 형식(한 줄 결론 + 바로 쓸 것 3개) → ④⑤ 행을 한 표에 함께(검토 서브 칸 ④/⑤ 유지, 조치 칸에 실제로 고친 파일·장면 id 또는 "반영 안 함 + 이유") → `## 통합 판단 기록`(부딪힌 의견과 정한 이유) → `## 통합 후 검증` (스크립트 핵심 수치).
