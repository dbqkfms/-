## 기준과 읽는 법

- **대본:** 02 v5.1 최종본의 문장과 A-4의 장면 id·순서를 그대로 썼다(통합 서브, 2026-10-21).
  - v5에서 바뀐 10줄(T02a·T18a·T23·T44·T53·T59·T60·T69·T70·T84g)을 내레이션 칸·시간·JSON 블록에 모두 반영했다. JSON 블록 단어 수는 1,540으로 02의 wc_script 단어 수와 같다.
  - T80은 v5 문장 그대로다(새 문장 보류, 메인 판단 7).
- **시간:** 장면 시간 = 문장 단어 수 ÷ 165 × 60초다. 무대사 장면은 T68 1.2초, T84d 0.8초를 더했다. 장면 안 컷은 구절 단어 수 비율로 나눴다. 예외는 T03 한 곳으로, Tesla 인용 컷을 3.0초 안쪽(2.9초)으로 고정했다(구절 끝 'wheels'는 다음 컷에 살짝 걸침). 전체는 1,540단어, 562.0초(9분 22.0초)다. 대본 02는 쉼을 넣어 약 9분 57초로 추정했으므로, 실측 뒤 시간 열을 다시 맞춘다.
- **화면 재료 분류:** 6종 정의(본문 1번)를 다음과 같이 적용했다.
  - 실사: 라이선스 표에 있는 실제 사진. 실제 사진끼리 합성한 것(T52)도 실사로 셌다.
  - 실영상: 실제 촬영 영상. 무료 스톡, NASA 영상, Tesla 짧은 인용이 여기에 든다.
  - 도해: 직접 그리는 설명 그림, 화살표, 표, 우리 UI 그래픽.
  - 문서: 실제 기사·게시물·공식 문서의 문구를 15단어 이하로 재조판한 카드, 또는 문서 표지 캡처.
  - 생성 그림: B급 만화 로봇 정지 그림이다. 밀기·시차·효과만 얹은 것도 여기에 든다.
  - 움직이는 클립: 우리가 만드는 움직이는 그림이다. 캐릭터나 물체가 실제로 움직이는 것, 재현 클립, 2D 컷아웃 애니메이션이 여기에 든다.
- **확정사항 반영:**
  - 실사풍 생성 그림은 0컷이다. A-10의 실사 느낌 생성 4개(T52·T67a·T73·T75)는 실사 합성, 무료 스톡 실영상, 만화 움직이는 클립으로 바꿨다.
  - H3와 Higgsfield 경로는 0곳이다.
  - T63 트럼프 클립은 삭제했다(본문 8번). 대신 우리 경고창 'CONTROLLER DISCONNECTED' 도해를 쓴다.
  - T02a의 'BOSS' 액자 컷과 '@grok' 글자는 쓰지 않는다(메인 판단). 회사명 없는 'is this real?' 말풍선과 SlashGear 기사 제목 카드만 쓴다.
  - 은빛 차는 C판(둥근 실루엣)으로 확정됐다.
- **Tesla 공식 영상:** 그대로 쓰지 않는다. 짧은 인용('Video: Tesla' 칩, 소리 없음)만 7곳에 쓴다(Q1 T01 · Q2 T03 · Q3 T05 · Q4 T18a · Q5 T22 · Q6 T32 · Q8 T84f). 곳마다 Tesla 원본은 3.0초 이하다(B-1 '1–3초', 검토 ⑤). 화면 길이로는 1.5–2.9초이고, T84f는 4.3초 컷 가운데 앞 1.3초가 T84e-2 안내판의 연속(새 화면이 아니라 컷을 나누지 않음)이고 Tesla 원본은 뒤 3.0초(정상 속도)뿐이다(통합 마무리 때 다시 확인). 합계 약 17초다(메인 상한 9곳 안).
  - Q7(T45 0-60 클립)은 X 원본이 1.04초뿐이라 늘려 쓰지 않는다. 무료 스톡 디지털 타이머 실영상과 Tesla 문구 칩('0-60 mph in 0.81 seconds')으로 바꿨다.
  - T19·T83의 정점·착지 프레임은 Tesla 프레임이 아니라 우리가 그린 R2 재현 그림이다(인용 수에 넣지 않음).
  - 나머지 Tesla 영상 자리는 도해, 재현 클립, 문서 카드로 바꿨다(자리별 기록은 05 파일).
  - 공정 이용 판단은 로컬 확인이 필요하다(미확인).
- **자막과 화면 글자:**
  - 자막은 화면에 굽지 않는 별도 층이고, 통통 튀는 영어 자막을 유지한다. 납품은 한글 자막판과 자막 없음판 두 판이고, .srt는 자막 없음판에 동봉한다.
  - 화면 글자(칩·카드·도장)는 그림 층이다. 자막과 같은 문장을 반복하지 않고 핵심어와 출처만 쓴다.
- **같은 그림 두 번까지:**
