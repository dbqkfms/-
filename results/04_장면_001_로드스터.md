# 04 장면표 — 편 1 테슬라 로드스터 (대본 v5 기준, 컷 189개)

**한 줄 결론:** A-4 v5의 100장면을 컷 189개·약 9분 20초(559.8초)로 나눴고, check04.py 기준 어김은 0개다(실사 22.8% · 움직이는 장면 38% · 30초마다 8–12번 교체 · 같은 재료 3연속 없음). Tesla 짧은 인용 8곳은 공정 이용 판단을 로컬에서 확인해야 한다.

**바로 쓸 것 3개**
1. 05 파일의 라이선스 표 순서대로 실사·실영상·문서 자료를 모으고, 고른 파일의 URL을 표의 `선정 전` 칸에 채운다. 무료 스톡 실영상 13개와 NASA 자료 5개가 먼저다.
2. Tesla 짧은 인용 8곳(Q1–Q8, `움직임 한 줄`에 표시)의 공정 이용 여부를 로컬에서 판정한다. 막히면 05의 'Tesla 공식 영상 대체 기록'에 적은 대체 컷으로 바로 바꾼다.
3. TTS를 실측한 뒤 `시간(초)` 열만 다시 계산한다(장면 안 컷 경계 비율은 유지). 그다음 `python3 -I check04.py`를 다시 돌린다.

## 기준과 읽는 법

- **대본:** A-4 장면순서 v5의 문장과 장면 id를 그대로 썼다.
  - T02a는 다른 서브가 "Grok tends to hype its own boss"를 사실 언급 문장으로 고치는 중이다. 그래서 내레이션 칸에는 첫 구절만 쓰고 `(v5.1 동기화 대기)`라고 표시했다. 시간은 v5 문장(21단어)으로 잡았고, JSON 블록도 v5 원문 그대로 두었다. 동기화는 메인이 한다.
  - T80은 A-10의 새 문장이 아니라 v5 문장 기준이다(메인 판단 7).
- **시간:** 장면 시간 = A-4 문장 단어 수 ÷ 165 × 60초다. 무대사 장면은 T68 1.2초, T84d 0.8초를 더했다. 장면 안 컷은 구절 단어 수 비율로 나눴다. 전체는 1,534단어, 559.8초(9분 19.8초)다. 대본 v5는 쉼을 넣어 약 9분 54초로 추정했으므로, 실측 뒤 시간 열을 다시 맞춘다.
- **화면 재료 분류:** 6종 정의(본문 1번)를 다음과 같이 적용했다.
  - 실사: 라이선스 표에 있는 실제 사진. 실제 사진끼리 합성한 것(T52)도 실사로 셌다.
  - 실영상: 실제 촬영 영상. 무료 스톡, NASA 영상, Tesla 짧은 인용이 여기에 든다.
  - 도해: 직접 그리는 설명 그림, 화살표, 표, 우리 UI 그래픽.
  - 문서: 실제 기사·게시물·공식 문서의 문구를 15단어 이하로 재조판한 카드, 또는 문서 표지 캡처.
  - 생성 그림: B급 만화 로봇 정지 그림이다. 밀기·시차·효과만 얹은 것도 여기에 든다.
  - 움직이는 클립: 우리가 만드는 움직이는 그림이다. 캐릭터나 물체가 실제로 움직이는 것, 재현 클립, 2D 컷아웃 애니메이션이 여기에 든다.
- **확정사항 반영:**
  - 실사풍 생성 그림은 0컷이다. A-10의 실사 느낌 생성 4개(T52·T67a·T73·T75)는 실사 합성, 무료 스톡 실영상, 만화 움직이는 클립으로 바꿨다.
  - H3와 Higgsfield 경로는 0곳이다.
  - T63 트럼프 클립은 삭제했다(본문 8번). 대신 우리 경고창 'CONTROLLER DISCONNECTED' 도해를 쓴다.
  - 은빛 차는 C판(둥근 실루엣)으로 확정됐다.
- **Tesla 공식 영상:** 그대로 쓰지 않는다. 짧은 인용(1.4–4.4초, 'Video: Tesla' 칩, 소리 없음)만 8곳에 쓴다(Q1 T01 · Q2 T03 · Q3 T05 · Q4 T18a · Q5 T22 · Q6 T32 · Q7 T45 · Q8 T84f, 합계 약 26초, 메인 상한 9곳 안).
  - 나머지 Tesla 영상 자리는 도해, 재현 클립, 문서 카드로 바꿨다(자리별 기록은 05 파일).
  - 공정 이용 판단은 로컬 확인이 필요하다(미확인).
- **자막과 화면 글자:**
  - 자막은 화면에 굽지 않는 별도 층이고, 통통 튀는 영어 자막을 유지한다. 납품은 한글 자막판과 자막 없음판 두 판이고, .srt는 자막 없음판에 동봉한다.
  - 화면 글자(칩·카드·도장)는 그림 층이다. 자막과 같은 문장을 반복하지 않고 핵심어와 출처만 쓴다.
- **같은 그림 두 번까지:**
  - 생성 그림 ID는 모두 2회 이하다(RS_044 T76·T88, RS_250b T82a·T84 입력).
  - 같은 사진도 2회 이하다(Tesla Semi T01·T07a, BT46B 후면 T11·T89, 김 서린 돋보기 T33·T65, COPV 사진 A T48·T87, 화성 사진 T42·T54a).
