# 06 모션계획 — 편 A(P03) 모기터짐

**한 줄 결론:** 움직이는 장면은 28/67 = 41.8%로 필수 30%를 넘고 권장 35–45% 안이다. 움직임은 실영상 2장면(L2 영상 편집)과 직접 만든 움직이는 클립(마스코트 연기·동화 집·도해 애니메이션)이 맡고, 나머지 39장면은 정지 그림에 카메라 밀기·팬·펀치인과 소품 등장 한 줄씩을 붙였다.

**바로 쓸 것 3개**
1. (로컬 실행) 아래 표의 "핵심" 클립부터 만든다: A-SH001(첫 화면, P03-01에만 씀), A-SH038 동화 집 전화(P03-33), A-SH045 전화선 느슨해짐(P03-38), A-SH048 전화 안 닿음(P03-40), A-SH050 계속 마심(P03-42), A-SH052 섬광(P03-44), A-SH062 며칠 외면(P03-53), A-SH078 반품(P03-66).
2. (공통 규칙) 생물(모기·마스코트·꼬마·교환원)만 눌림·튐을 쓰고, 소품·정보·카메라는 감속 정착한다. 소매·서류철·도장·구슬은 튀지 않는다. 포즈는 통교체로 바꾸고 머리·눈 같은 미세 리그는 만들지 않는다(B-7 5절).
3. (실영상 편집) L2 영상 S4는 960×540 원본을 2배로 키우고, 번인 라벨 4개를 흐리고, 붉은 블록이 덜 보이게 자른다. 소리는 끈다. 변경 사항은 05 라이선스 표대로 설명란에 적는다.

- 움직이는 장면 비율 계산: 움직이는 장면 = 장면 안 컷의 절반 이상이 실영상 또는 움직이는 클립인 장면. 28 ÷ 67 = 41.8%(엄격 과반 기준 22/67 = 32.8%). 컷 기준으로는 움직이는 클립 30컷 + 실영상 2컷 = 32/83컷. 마무리에서 P03-46은 도해 재사용으로 빠지고 P03-48에 움직이는 컷 하나가 더해졌다.
- 길이(초): 장면 시간(04, 추정) 중 움직이는 컷이 차지하는 길이. 2컷 장면에서 한 컷만 움직이면 절반이다.

## 정지 장면의 카메라 움직임 요약

정지 장면(생성 그림·도해·실사·문서가 다수인 장면)도 2–4초마다 무엇이 바뀌게 한다(E-3). 한 장면 안에 움직이는 컷이 하나 있으면 그 컷 메모를 함께 적었다.

- P03-02 (3-6, 생성 그림): 느린 밀기 100→112% 뒤 검은 화면으로 하드 컷(P03-21에서 같은 화면 재사용)
- P03-03 (6-10, 생성 그림): 모기 줄을 따라 왼쪽→오른쪽 느린 팬, 끝에서 마스코트 얼굴에 멈춤
- P03-04 (10-13, 도해): 느린 밀기 100→108% + 금색 실 밝기 한 번(편집 층)
- P03-06 (16-22, 생성 그림): 마스코트에서 구름으로 위 틸트, "pops"에서 빠른 펀치인 1번(구름은 터뜨리지 않음)
- P03-07 (22-25, 생성 그림): 느린 밀기 후 도장 순간 빠른 펀치인(카메라만, 소품은 튀지 않음)
- P03-09 (28-33, 생성 그림): 오른쪽으로 느린 팬, 열린 창문에서 멈춤(다음 장면 모기 들어올 자리)
- P03-11 (37-41, 생성 그림): 긴장을 쌓는 느린 밀기 100→115%, 끝 0.6초 정지
- P03-13 (45-51, 생성 그림): 컷1 느린 밀기, 컷2 자국 쪽 확대 + 자국 층 90→100% 정착(소품 등장)
- P03-14 (51-56, 생성 그림): 아래에서 위로 느린 틸트
- P03-16 (59-64, 생성 그림): 빈 종이 쪽 밀기 후 "myth"에 쭈그러든 구름으로 위 틸트
- P03-17 (64-66, 생성 그림): 빠른 펀치인 1번 후 정지
- P03-18 (66-70, 도해): 확대경 쪽 느린 밀기, 가장자리 마스코트는 고정
- P03-19 (70-74, 도해): 주둥이 끝→머리 펌프로 따라가는 밀기 + 펌프 밝기 두 번(편집)
- P03-20 (74-79, 생성 그림): 구름 쪽으로 느린 밀기, 마지막 0.6초 정지(웃을 틈)
- P03-22 (83-87, 도해): 모기 배를 따라 느린 밀기
