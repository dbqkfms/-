# 03 현지화 — 편 2 "AI 생물학 폭격" (한글 자막판용)

**한 줄 결론:** 한글 자막판 납품이 확정이라 현지화가 필요하다. 98장면 전부를 해요체 구어 자막으로 옮겼고(행 = 장면, handoff JSON 순서 그대로), 밈·말장난 18곳은 뜻이 살게 의역했다(아래 의역 메모).

**바로 쓸 것 3개:**
1. 한글 자막판을 렌더할 때 이 표의 '한국어 자막' 열을 장면 id 순서대로 별도 자막 층에 얹는다. 칸 안의 ` / `는 줄바꿈이고, 한 화면에 두 줄까지만 쓴다. 화면에 굽지 않는다.
2. 음성 실측 뒤 장면 id별 시작·끝 시각을 붙여 한국어 자막 파일로 바꾼다. 영어 .srt는 영어 원문 열로 따로 만들어 자막 없음판에 동봉한다(02 대본의 자막·납품 명세).
3. 검토 서브 ④는 '의역 메모'의 18곳이 영어 농담의 낙차를 살렸는지, 검토 서브 ⑤는 숫자·날짜·인물 이름이 영어 원문과 같은지(S2-15·27·35·37·49·55·59·66·84) 본다.

**표기 규칙:** 모델·회사·논문 이름은 영어 그대로 쓴다(AlphaProteo, AlphaFold2, RFdiffusion, Profluent, OpenCRISPR-1, EvolutionaryScale, ESM3, esmGFP, BHRF1, Cas9, Nature). 인물은 한글(데미스 허사비스, 존 점퍼, 데이비드 베이커), 기관은 한국어 통용 표기(구글 딥마인드, 프랜시스 크릭 연구소, 핵위협방지구상(NTI))로 쓴다. 숫자는 아라비아 숫자로, 영어 원문의 추정 표기("Reportedly")는 "보도에 따르면"으로 반드시 살린다(S2-55).
