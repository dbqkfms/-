## 편 전체 약속

- **마스코트 그림체(편마다 안 바꿈):** 크림색 둥근 몸, 두꺼운 청록색 동그란 안경, 머리 위 산호색 물음표 더듬이 하나, 작은 짙은 점 눈(작은 흰 반사점), 분홍 볼, 얇은 남색 외곽선, 탐정 모자 없음(E-6 P01, B-5 공통). 놀람은 눈을 키우지 않고 입·자세로 한다. 밝은 동화풍 2D 평면 손그림, V7 부품 규격 그대로.
- **색 규칙:** 먹은 한 끼 = 루비(구슬·줄무늬, 액체 튐 없음) / 오줌 = 연하늘 투명 / 신경·전화 = 금색 / 화학 쪽지·약 = 라벤더 / 터짐 섬광 = 흰·노랑 별(붉은색 금지) / 1969 = 밝은 세피아(마스코트만 원래 색) / 2019 = 흰·청록 / 마스코트의 상상 = 굵은 생각 구름 테두리.
- **실제와 비유를 가르는 틀:** 놋쇠 확대경 테두리(AX02) = 실제 모기 몸을 그린 도해. 테두리 없는 동화 집 = 비유. 실사·실영상·논문 그림 = 테두리 없이 전체 화면. 이 약속을 끝까지 바꾸지 않는다(B-5 판단 필요 5, B-8 #54 해결).
- **반복 소품:** 근육 소매(P03-05 착용 → 21 탁자에 내려놓음 → 50·65 탁자 위 → 66 반품), 글자 없는 도장 "Case closed"(07 서류철 → 26 물풍선 → 54 허공 → 67 반품 상자, 매번 변주), 서류철(07·08·16·55·57), 깡통전화(34·36·37·47), 확대경(03·22), 파란 물풍선(26).
- **첫 구도로 돌아오는 끝:** P03-01 썸네일 구도 → P03-46 같은 화면으로 같은 질문 → P03-65·67 같은 각도의 실험실에서 반품 상자에 도장으로 닫는다.
