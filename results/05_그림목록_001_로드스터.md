# 05 그림목록 — 편 1 테슬라 로드스터 (04 장면표 기준, 생성하지 않음)

**한 줄 결론:** 100장면마다 화면 재료, 장수(컷 수), 참조 그림, 금지 요소를 적었다. 생성 그림은 31컷(새 그림 20장, 기존 그림 10종 11컷)으로 A-6 계획보다 크게 줄었다. 외부 자료 가운데 라이선스 미확인은 9건이다(Tesla 인용 원본 3건 = 8곳, NASA/JPL 개별 자료 5건, Commons 레이스카 1건). 모두 대체안을 적었다.

**바로 쓸 것 3개**
1. 아래 '생성 담당에게'의 새 그림 20장을 은빛 C판 기준으로 발주한다(RS_000.png 참조, 같은 그림은 두 번까지). 경로는 로컬에서 고르되 Higgsfield 크레딧 경로와 H3는 쓰지 않는다.
2. 라이선스 표에서 '선정 전'인 무료 스톡(Pexels License)과 NASA 자료를 고르고, 고른 파일의 URL을 표에 적는다. 얼굴·번호판·로고가 없는 것만 고른다.
3. Tesla 짧은 인용 8곳의 공정 이용을 로컬에서 판정한다. 막히면 'Tesla 공식 영상 대체 기록'의 대체 컷으로 바꾸고, 04의 배합 보정안(T61a-1·T87-1·T64-1·T89-3)을 함께 적용한다.

## 읽는 법

- 형식은 본문 9-4를 따른다. 행 하나가 장면 하나(컷 번호 없는 id)이고, `장수`는 그 장면의 컷 수다.
- 한 장면에 화면 재료가 섞이면 주재료를 적었다. 주재료는 그 장면에서 가장 많은 재료이고, 수가 같으면 첫 컷의 재료다. 섞인 장면은 표 아래 '장면 안 재료 내역'에 컷 단위로 따로 적었다.
- 이 파일은 필요 목록이다. 그림·영상은 만들지 않았고 받지도 않았다.
- 은빛 차는 C판(둥근 실루엣)으로 확정됐다(메인 판단 6). A-6의 'B·C 두 판'은 모두 C판 한 판으로 바꾼다.
- **6종 공통 금지:** 표의 `금지 요소` 칸에는 주재료의 공통 금지와 그 장면에만 해당하는 금지를 적었다. 섞인 재료가 있으면 '+ ○○ 공통 금지'로 표시했다.
  - 생성 그림: 실존 인물 사실적 얼굴, 실사풍, 저작권 캐릭터·밈 원본 복사, 회사 로고, 그림 속 글자·숫자, 불꽃(가스는 흰 찬 가스)
  - 움직이는 클립: 실사풍, 실존 인물 생성 영상(2D 컷아웃만), 로고, 불꽃, 새 캐릭터 추가, 배경 흐름
  - 실사: 라이선스 표 밖 사진, 얼굴·번호판·로고가 주인공인 사진, Tesla 실제 기록처럼 보이게 쓰기
  - 실영상: 라이선스 표 밖 영상, 얼굴·번호판, 원본 소리, Tesla 인용 4.5초 초과
  - 문서: 15단어 넘는 인용, 원문 바꾸기, 출처 칩 없는 인용, 개인 사용자명 노출
  - 도해: 실제 게임·앱 UI·로고 복제, 자막과 같은 문장 반복, 작업 메모·"미확인" 글자
  - 생성 그림은 글자를 편집 층에 넣는다. 실존 인물(Altman·Musk)은 이름표 로봇 2D 컷아웃으로만 그리고, 생성 영상으로 돌리지 않는다.
