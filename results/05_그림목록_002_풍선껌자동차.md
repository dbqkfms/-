# 05 그림목록 — 002 풍선껌자동차

**한 줄 결론:** 64장면에 완성 화면 73개가 새로 필요하다(그 밖에 재사용 컷 2개, 컷 75개). 이 화면들을 조립하려면 새 그림 **51장**을 그려야 한다(배경판 2·상상 테두리 1·마스코트 포즈 21·소품 20·도해 7, 시트 포함, 상태 칸 합 76). 외부 자료는 라이선스를 직접 확인한 실사 3건만 쓴다. 확인했던 실사 1건·문서 2건은 2차 검토 마무리 때 빼서 '미사용'이다. 실영상과 논문 캡처는 없다. 정본 동기화 완료.

**바로 쓸 것 3개**
1. 그림 생성 담당(로컬): '3. 새 부품 목록' 51장을 만든다.
   - 매 주문에 정체성 기준 그림(E-6 `P01_기본.png`·`마스코트_기준.webp`, 편 A와 같은 두 장)을 첨부한다.
   - 규격은 0절대로 맞추고, 그림 안에 글자·숫자·로고를 넣지 않는다.
   - 시트는 한 장에 상태를 나란히 그린다.
2. 편집 담당: 라이선스 표에서 '사용'인 외부 자료 3건(B-RP01·03·04)만 표의 URL에서 원본으로 받는다. '미사용' 3건(B-RP02·B-DC01·B-DC02)은 받지 않는다.
   - '사용 조건'대로 설명란에 출처를 적는다(화면에 굽지 않음). B-RP03은 'Bodie Strain' 표시와 Flickr 원본 링크를 꼭 넣는다.
   - B-RP04의 손가락처럼 잘라 낼 곳을 먼저 자른다.
3. 조립 담당: '2. 완성 화면 id 사전'의 73개 화면(B-SH027은 삭제)을 부품으로 조립한다. ★ 21개 핵심 장면을 먼저 만든다. 재사용은 B-SH003(GUM-56)과 B-SH016(GUM-47) 둘뿐이다.

## 0. 공통 규격 (두 편 같게)

- **그림체:** 밝은 동화풍 2D 평면 손그림, 얇은 남색 외곽선, 단순한 색면. 편 A(B-5 공통)와 같다.
- **마스코트:**
  - 크림색 둥근 몸, 두꺼운 청록색 동그란 안경, 산호색 물음표 더듬이 하나, 작은 짙은 점 눈(흰 반사점), 분홍 볼, 탐정 모자 없음.
  - 정체성 기준은 E-6 P01이다. 주문에 `eyes exactly like the attached P01 (small solid dark dot eyes, no large irises)`를 넣는다.
- **규격:**
  - 배경판은 16:9, 2400×1350 이상.
  - 마스코트 포즈는 1254×1254 정사각 투명 PNG이고 발 위치를 같게 맞춘다(편 A V7 부품과 같은 규격).
  - 소품·도해·보조 그림은 투명 PNG.
  - 생성 도구가 투명 배경을 못 내면, C-6처럼 단색 중간 회색 바탕으로 받아 오려 낸다.
- **글자:** 그림 안에는 글자·숫자·로고·번호판 글자·포장 글자를 넣지 않는다. 칩과 카드 글자는 모두 편집 층에 둔다(04 1절 6).
- **안전·권리:**
  - 차나 매단 물건 아래·근처에 사람·마스코트를 그리지 않는다.
  - 실존 인물 얼굴, 실존 제품의 포장 모양·색 조합, 논문 그림을 그대로 베끼지 않는다.
- **이 목록에서 '장수'의 뜻:**
  - 장면표의 '장수' 칸 = 그 장면에서 새로 조립할 완성 화면(컷) 수와 id.
  - '새 그림' = 3절의 부품(생성 대상).
  - 외부 실사·문서 화면은 생성하지 않고 잘라 쓴다.
- **같은 그림 2회 이하:** 완성 화면 id 단위로 센다(04 0절의 해석). 같은 완성 화면 id는 2개 장면 이하로만 쓴다.
