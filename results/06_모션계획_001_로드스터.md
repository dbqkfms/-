## 경로를 바꾼 곳과 이유 (A-6 → 이번 계획)

확정사항 충돌은 다음 원칙으로 처리했다. 본문 2번(로컬 H3 제외, Higgsfield 크레딧 경로 안 씀)이 A-1의 H3·Higgsfield 줄보다 우선한다(메인 판단 1). 실사풍 생성 그림·영상은 쓰지 않는다(본문 1번 용어집, 메인 판단 2). 바꾼 경로는 셋 중 하나다: 움직이는 클립(직접 만든 움직이는 그림), 정지 그림에 움직임 입히기, 라이선스가 허용된 실영상.

- **A-6 ① 로컬 H3 4장면 + A-10의 H3 2곳 → H3 제외.**
  - VL_T02a(비서 로봇 액자 닦기): T02a 문장이 v5.1로 바뀌는 중이라 클립 자체를 보류했다. 도해 답글 폭포와 문서 카드로 둔다.
  - VL_T03(리모컨·팝콘): 정지 그림에 움직임을 입힌다(RS_141 밀기 + 팝콘 통 누끼 낙하).
  - VL_T26(근육 구름): 라이선스 허용 실영상(NASA 대기 영상)으로 바꿨다. 'atmosphere'를 실제 대기로 보여 주는 편이 그림보다 낫다고 판단했다.
  - VL_T13(렌치·차 앞 출렁): 실사(큰 모터 사진)와 실영상(출발 바퀴)으로 바꿨다.
  - RS_250c 일어서기(T84g, A-10에서 H3 1초): 움직이는 클립으로 바꿨다. 짝 그림 RS_250b → RS_250c 사이를 직접 움직인다.
  - T75 ROBO 올려다보기(A-10에서 H3 1.2초): 정지 그림에 움직임을 입힌다. 'HOLY MOLY' 글자만 튄다.
- **A-6 ③ Higgsfield Unlimited 영상 5개(VH_T21·VH_T37·VH_T51·VH_T89b·VH_T91) → 쓰지 않음.**
  - 'Higgsfield Unlimited'가 크레딧을 쓰는지 클라우드에서 확인할 수단이 없다. 확인하지 못하면 쓰지 않기로 정했다(메인 지시).
  - 다섯 장면 모두 움직이는 클립으로 바꾼다. 같은 짝 그림(첫·끝 프레임) 사이를 직접 움직인다. 실행 메모의 '몇 초 안에 무엇' 기준은 A-6의 '지루하지 않으려면' 줄을 그대로 옮겼다.
  - 그림 생성 경로로 A-6 공통 조건에 적힌 'Higgsfield Nano Banana Pro'도 같은 이유로 빼고, 로컬에서 다른 경로를 고른다.
- **A-6 ②·A-10의 실사풍 생성 영상 → 쓰지 않음.**
  - VO_T50_R(T52 탱크)은 실사 합성(정지 사진 + 버클 급줌)으로 바꿨다.
  - VO_T73_R(헬기)은 만화 움직이는 클립(정체 위로 솟음 + 수배 별)으로 바꿨다.

  - VV_T75_R(POV)은 무료 스톡 운전석 시점 실영상에 만화 차 누끼를 얹는 것으로 바꿨다.
  - 이 네 곳은 원래 'AI-generated' 칩을 붙이려던 자리인데, 이제 실사풍 생성이 없으므로 칩도 필요 없다.

  - VO_T54a는 2D 컷아웃 움직임(T54a 상자·노즐)으로 바꿨다. 이름표 로봇은 생성 영상으로 돌리지 않는다.
  - VO_T84g는 T84g의 예약자 벌떡 일어나기로 자리를 옮겼다. 소파 박수는 정지 그림이다.
- **트럼프 클립(T63, A-10) → 삭제(메인 판단 3).** T63은 움직이는 장면에서 빠지고, 경고창 도해 한 컷이 됐다.
- **Tesla 짧은 인용 8곳(T01·T03·T05·T18a·T22·T32·T45·T84f):** 실영상으로 셌다. 공정 이용 판단이 로컬에서 막히면 T45는 무료 스톡 스톱워치 실영상으로, 나머지 7곳은 재현 움직이는 클립으로 바뀐다. 어느 쪽이든 움직이는 장면으로 남으므로 38%는 바뀌지 않는다. T64·T89를 도해로 돌리는 04의 배합 보정안을 함께 쓰면 37%다(T64·T89는 빠지고 T87이 들어온다).

## 어지러움 막기 (B-1 5번, 이번 계획에 적용)

- 한 화면에서 크게 움직이는 것은 하나만 둔다. 카메라 흔들기는 쓰지 않는다. 화면 쿵 흔들림은 펀치 정점에서만 1회(T59·T84c·T85)다.
- 실영상 사이에는 최소 3컷을 둔다. 예외는 콜드 오픈 T03-1 → T05-1(2컷) 한 곳이다(04 판단 2).
- 움직임의 정점은 강세 단어 ±0.15초에 맞춘다. 펀치 뒤 반응은 0.5–1초 멈춘다(T29·T52·T68·T84d).
- 클립은 04의 컷 길이보다 길게 쓰지 않는다(남는 부분은 자른다). 속도감이나 내용이 지루한 클립은 탈락시키고 정지 그림 + 움직임으로 되돌린다(A-1 10-21).
