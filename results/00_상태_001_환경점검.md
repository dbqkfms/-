# 00 상태 001 — 환경 점검 (2026-10-21)

**한 줄 결론:** 웹 검색·웹 페이지 열기는 되므로 6개 과제를 모두 진행합니다. 다만 Reddit 일반 페이지, 나무위키, theqoo, fmkorea, 뽐뿌, Science·AIP 논문 페이지, GitHub API는 막혀 있습니다. 이 사이트들은 RSS·검색 결과·다른 경로로 우회하거나, 막혔다고 적고 넘어갑니다.

**바로 쓸 것 3개**
1. Reddit은 `https://www.reddit.com/r/<서브>/search.rss?q=<검색어>&restrict_sr=1&sort=top&t=month` RSS로 읽힙니다(200, 실제 글 제목 확인).
2. YouTube 설명과 댓글은 `yt-dlp --js-runtimes node --write-comments`로 받을 수 있습니다. 반복 요청하면 429(요청 과다)가 나므로 간격을 둬야 합니다.
3. GitHub 저장소는 웹 페이지 열기 도구와 `raw.githubusercontent.com`으로 읽힙니다. `api.github.com`과 curl로 여는 github.com 웹 페이지는 403입니다.

## 1. 작업 저장소 관련 확인 사항 (중요)

| 항목 | 상태 | 비고 |
|---|---|---|
| 요청서의 저장소 이름 | `claude-cloud-work` | 계정에서 접근 가능한 저장소 목록(11개)에 이 이름은 **없습니다** (2026-10-21 확인) |
| 실제 세션 저장소 | `dbqkfms/-` (THISGLOBAL 웹사이트 저장소) | 이 세션에 연결된 저장소는 이것 하나입니다 |
| 작업 브랜치 | `claude/friendly-goodall-3fqy7i` | 결과는 모두 이 브랜치의 `results/` 아래에 push합니다 |
| `inputs/` 폴더 | **없음** (main 포함 모든 브랜치에 없음) | 요청서의 '채널 요약'만으로 진행합니다 |

- **추천안:** 사용자 PC가 자동으로 받아 가는 대상이 `claude-cloud-work`라면, 이번 결과는 `dbqkfms/-` 저장소의 `claude/friendly-goodall-3fqy7i` 브랜치에 있습니다. 자동 수신 경로를 확인하거나 `results/` 폴더를 옮겨야 합니다. 웹사이트 코드(`src/`, `public/`)는 건드리지 않았습니다.
- 과제 1의 '소재 풀 후보'는 inputs에 없어서, 채널이 이미 다룬 4개 편(나비에-스토크스·리만 가설·밀레니엄 7대 난제·테슬라 로드스터)의 핵심 주장을 검증 대상으로 삼았습니다.

## 3. 웹 접근 시험 결과 (2026-10-21, curl User-Agent `research-bot/1.0`)

| 대상 | 결과 | 쓰는 방법 |
|---|---|---|
| 웹 검색 도구 | 정상 | 기본 조사 수단 |
| 웹 페이지 열기 도구 (Wikipedia, GitHub 웹 페이지) | 정상 | 이 도구는 User-Agent를 직접 정할 수 없습니다(도구 자체 값 사용) |
| Reddit 일반 페이지 / `.json` | **차단** (웹 페이지 열기 도구: 열 수 없음, curl: 403) | RSS로 우회: 서브레딧·검색·글 댓글(`/comments/<id>/.rss`) |
| Reddit RSS | 200 | 검색 RSS로 실제 글 제목을 받았습니다 |
| YouTube | 페이지 200, 첫 요청 때 429 한 번 | yt-dlp + node로 설명과 댓글 수집 성공 |
| X(x.com) | 첫 화면 200, 개별 글 404(로그인 필요로 추정) | 검색 결과와 nitter(200)로 우회. 실패하면 '미확인' |
| GitHub | 웹 페이지 열기 도구 정상, raw 200, API 403, curl 웹 403 | 웹 페이지 열기 도구와 raw로 읽음 |
| Hugging Face (API·파일) | 200 | 모델 카드·라이선스 확인 |
| 디시인사이드 · 클리앙 · 루리웹 · 인벤 · 개드립 | 200 | 한국 커뮤니티 반응 |
| theqoo · fmkorea · 뽐뿌 · 나무위키 | **차단** (403/430) | 검색 결과 요약으로만 참고하고, 원문은 '미확인'으로 표시 |
| note.com · Zenn · Qiita · 5ch(리다이렉트) | 200 | 일본 커뮤니티 반응 |
| TikTok · Instagram | 첫 화면 200 | 개별 게시물은 로그인 장벽 가능성이 있어 결과마다 표시 |
| 한국고전종합DB(db.itkc.or.kr) · 한국학자료센터 · 국립중앙도서관 · 공공누리 · 위키문헌 | 200 | 야담 원전 확인 |
| Project Gutenberg · sacred-texts · theoi · archive.org · Wikimedia Commons | 200 | 신화 원전과 퍼블릭 도메인 자료 |
| Perseus(tufts) | 응답 없음(000) | 다른 판본 사이트로 대체 |
| NASA 이미지 · ESA · arXiv · Nature | 200 | 긴급과학 원출처 |
| Science.org · AIP(pubs.aip.org) | **403** | 해당 논문은 DOI·arXiv·보도자료로 교차 확인하거나 '미확인' |
| Civitai API | 200 | 모델 실사용 예시 |

## 4. 지킨 규칙
- 유료 API, 결제, 계정 생성은 하지 않았습니다. 웹 요청에 개인정보를 넣지 않았습니다(curl·yt-dlp는 User-Agent `research-bot/1.0`).
- 인용은 15단어 이하로 했고, 노래 가사는 넣지 않았습니다.
- 다운로드한 파일은 스크래치 폴더 안에 따로 격리했습니다.
