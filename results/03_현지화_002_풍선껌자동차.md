# 03 현지화 — 002 풍선껌자동차 (한국어 자막)

**한 줄 결론:** 영어 낭독본 v2를 장면 id(GUM-01–GUM-64) 단위로 한국어 자막에 1:1로 옮겼다. 해설은 해요체, `MASCOT:` 줄은 반말이며, 셀 안의 " / "가 자막 줄바꿈이다(한 줄 22자 이하, 대부분 10–20자).

**바로 쓸 것 3개**
1. 자막 층(.srt/.ass) 만들 때: 장면 id의 시작–끝 시각(04 장면표)에 이 셀을 그대로 넣고, " / "마다 줄을 바꾼다. 한 화면에 두 줄까지, 세 줄 이상인 셀(17개: GUM-08·GUM-11·GUM-12·GUM-16·GUM-21·GUM-23·GUM-24·GUM-27·GUM-29·GUM-36·GUM-39·GUM-40·GUM-47·GUM-54·GUM-56·GUM-58·GUM-62)은 " / " 단위로 화면을 나눠 띄운다.
2. 숫자 표기는 이 표대로 통일: 700개·900개·2천 개·1만 2천 개·17뉴턴·1뉴턴·100그램·300그램·7분·7센티미터·약 1,200kg. 영어에서 'roughly / somewhere / about / probably / my best guess'인 곳은 한국어도 '대략·쯤·약·아마·제 짐작엔'으로 추정임을 남겼다 — 자막 줄이 길어도 이 말은 빼지 않는다.
3. 한국어 TTS를 따로 만들 경우: 해설은 말끝을 내리지 않는 들뜬 해요체, 마스코트는 허세 부리다 기죽는 반말(부록 B-9 결). "떴다, 떴다, 사건 종결!"은 신나게, 마지막 "아주, 아주, 아주 천천히."는 한 박씩 늘어지게.

번역 원칙: 뜻은 영어와 같게, 말맛은 한국어로 다시 쓴다. 영어 말장난을 그대로 옮기기 어려운 줄은 같은 기능의 한국어 드립으로 바꿨다 — GUM-28 "my jaw already quit" → "내 턱은 벌써 파업했어", GUM-34 "a noodle with ambitions" → "꿈만 큰 국수 가락", GUM-50 "quietly parked itself again" → "조용히 다시 주차한 거죠". 사실 범위·추정 표시는 바꾸지 않았다.
