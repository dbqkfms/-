## 0. 기준과 세는 법

- **정본:** `편B_장면순서.json`(md5 `a12f67aa929d92f57a3b6a1eb3bfb202`, 2026-10-21 08:08 수정판, 64개, 699단어). 내레이션 구절 칸은 JSON text를 글자 그대로 옮겼다. 화자와 궁금증 갱신 지점은 02 개정판(부가 2절 화자표, 질문 흐름)을 따른다. 마스코트 대사 장면은 GUM-03·07·12·20·29·31·36·44·51·53·61·64다.
- **시간:** 장면마다 (단어 수 ÷ 2.7) + 숨·반응 박자를 누적한 뒤 반올림했다. 박자는 기본 0.35초, 웃음·반전·안전 문장 뒤는 0.5–1.5초다. 그래서 시간은 0부터 빈틈없는 정수다. 낭독 어림 258.9초 + 박자 30.1초 = 289초(상한 295초 안). 첫 질문(GUM-02)은 11초에 끝난다.
- **컷:** 컷 하나 = 화면 교체 한 번 = 완성 화면 하나. 30초 구간 컷 수는 공통지침대로 센다. 장면 안 컷을 장면 길이에 고르게 놓고, 컷 시작 시각이 속한 구간에 넣는다.
- **화면 재료 칸:** 그 장면 컷 가운데 가장 많은 재료다. 컷이 1:1로 같은 수인 장면(GUM-08·17·19·21·24·37·46·62)은 움직이는 클립이 있으면 움직이는 클립으로 적는다. 움직이는 장면을 '컷의 절반 이상'으로 판정하는 기준과 맞추기 위해서다. 움직이는 클립이 없으면 첫 컷 재료로 적는다(GUM-08 = 생성 그림). 재료가 섞인 장면은 움직임 칸 끝에 `[컷: …]`으로 적었다.
- **완성 화면 id 해석(로컬 판정 질문 후보):** 배경판·마스코트 포즈 같은 부품은 여러 컷에 써도 된다. 컷마다 구도·소품·움직임이 다르면 다른 완성 화면으로 본다. 같은 완성 화면 id는 2개 장면 이하로만 쓴다. 이 편에서 재사용한 화면은 B-SH003(GUM-02·56, 첫 질문 되묻기)과 B-SH016(GUM-14·47, 늘어나는 껌 실사) 둘이다.
- **실영상 0건:** Wikimedia Commons에서 껌·꿀·크레인 실제 영상을 찾았다. 브랜드와 사람이 없고 CC0·CC BY·퍼블릭 도메인인 영상은 없었다. 찾은 영상은 CC BY-SA이거나, 아이·상표(µCT 껌 영상)가 나왔다. 그래서 움직이는 장면은 모두 직접 만든 움직이는 클립으로 채웠다(05 '못 쓴 자료').

## 1. 편 전체 약속

1. **마스코트 그림체 고정(편 A와 같음).**
   - 그림체: 밝은 동화풍 2D 평면 손그림, 얇은 남색 외곽선, 단순한 색면.
   - 모습: 크림색 둥근 몸, 두꺼운 청록색 동그란 안경, 머리 위 산호색 물음표 더듬이 하나, 작은 짙은 점 눈(작은 흰 반사점), 분홍 볼, 짧은 팔다리, 탐정 모자 없음.
   - 놀람은 눈을 키우지 않고 입과 자세로 보인다.
   - 정체성 기준 그림은 편 A와 같은 두 장이다(E-6의 `P01_기본.png`, `마스코트_기준.webp`).
   - C-6의 A20 방향시안·V8LIB는 배경·연기 부품으로만 참고한다. 얼굴은 P01에 맞춘다.
2. **색 규칙.**
   - 껌 = 분홍. 씹은 껌은 진분홍, 판 사이 패드도 같은 분홍이다.
   - 침(인공 침 포함) = 투명한 하늘색 물방울 + 흰 반사점.
   - 자동차 = 불투명한 진한 하늘색 작은 둥근 차. 투명한 침과 섞여 보이지 않게 한다.
   - 판: 플라스틱 판 = 우윳빛 반투명 흰색, 금속 판 = 은회색.
   - 크레인 = 노랑, 안전선 = 노랑·검정 줄무늬.
   - 실험 껌(자일리톨) = 민트색 판껌.
   - 칩: 숫자 칩 = 흰 바탕 + 남색 글자(강조 하나만 산호색), 경고 칩 = 노랑 바탕 + 남색 글자.
3. **반복 소품: 신발 껌 실.**
   - GUM-01에서 밟은 분홍 실은 마스코트 전신이 보이는 컷마다 오른발 밑에 짧게 남는다(B-OB01 '짧게').
   - GUM-62–64에서 '아주 길게'로 회수한다. 실은 끝까지 끊기지 않는다.
4. **첫 구도로 돌아오는 끝.**
   - GUM-64는 GUM-01 첫 컷과 거리(L12_06)·카메라 높이(허리)·가로등 자리(화면 오른쪽 3분의 1)가 같다.
   - GUM-56은 GUM-02의 첫 질문 화면(B-SH003)을 그대로 다시 써서, 같은 질문을 같은 그림으로 되묻는다.
5. **자막은 별도 층.**
   - 자막은 화면에 굽지 않는다.
   - 납품: 한글 자막판 = 03 자막 층, 자막 없음판 + 영어 .srt.
   - 화면 아래 약 15%는 자막 자리로 비워 둔다. 칩과 중요한 소품을 그 자리에 두지 않는다.
6. **화면 글자·숫자 칩은 영어로, 크게(화면 높이 6–9%).**
   - 칩에는 대본에 나온 값과 핵심 단어만 쓴다: `A MILLION?` `1,200 kg` `TOKYO` `REENACTMENT` `5 min` `17 N` `XYLITOL GUM` `BUBBLE GUM` `~700` `~900` `DON'T TRY THIS AT HOME` `under 1 N` `< 100 g` `~12,000` `½ thick → 4× stress` `PLAN B` `900` `IMAGINE` `300 g` `7 min` `7 cm` `~700–900` `FOREVER?` `HOW MANY?` `HOW MANY SECONDS?`
   - 그림 안에는 글자를 넣지 않는다. 칩은 편집 층에 둔다.
   - 한국어는 자막 층에만 쓴다.
7. **안전.**
   - 차와 매단 물건(추·병) 아래나 근처에 사람·마스코트를 두지 않는다.
   - 크레인 장면에서 마스코트는 늘 노랑·검정 안전선 밖에 있고, 안전모를 쓰고 원격으로 조작한다.
   - 잭으로 들기, 차 밑에 들어가기 장면은 없다.
   - 매다는 물건은 낮은 높이에 둔다.
   - 900개 씹기는 과장이 분명한 만화로만 그리고 경고 칩을 붙인다.
8. **재현·상상 표시.**
   - 실험을 마스코트가 따라 하는 장면(GUM-08·09·23·48)에는 `REENACTMENT` 칩을 단다. 연구자·학생의 얼굴과 이름은 쓰지 않는다.
   - 크레인 장면(GUM-40·41·43–46·53–55·61)은 생각 구름 테두리(B-AX01)를 유지해 '상상 실험'으로 읽히게 한다.
   - GUM-42의 실제 규정 문서 컷만 테두리가 없다(현실 규칙이기 때문).
9. **움직임 규칙(편 A와 같게).**
   - 눌림·튐은 생물(마스코트, 껌 덩이 일꾼)만 한다. 소품·정보·카메라는 감속 정착하고 튀지 않는다.
   - 껌은 '늘어남'으로만 보인다. 끊어지는 '뚝' 소리는 쓰지 않는다. 끝까지 안 끊기는 것이 이 편의 답이다.
   - 감정 기호는 박자 하나에 하나만 쓴다.
   - 웃음 뒤에는 0.5–1초 정적을 둔다(GUM-12·19·26·29·36·44·51·55·64).
10. **질문 신호.** ○ 장면(마스코트가 보이는 컷)과 GUM-02·56에서 더듬이가 튀고, 채널 공통 효과음을 한 번 낸다. 마스코트가 안 보이는 ○ 컷(GUM-45 등)은 효과음만 넣는다.

## 4. 옛 지적 반영

2. **"몇 개를 붙이든 결국 내려온다"는 단정이 지나치다:**
   - 차가 놓치고 내려오는 장면(GUM-45·46·54·55)은 모두 상상 테두리 안에 두었다.

   - 많이 붙이면 '느려진다'(GUM-54, 달팽이와 같은 빠르기)를 '닿는다'(GUM-55)보다 먼저 보인다.

4. **치과 연구·풍선껌 질김·학생 실험의 출처가 모호하다:**
   - 논문과 학생 웹 기록 화면은 캡처하지 않았다(권리).
